################################
#	Scrolling on the map.
################################
- while using the app the user shall be able to focus on walking / hunting or anything else,
so usually the screen follows the user position within a specified range. Repositioning will
happen every other 10 - 20 meters, this needs to be decided or maybe the distance will also 
change with the zoom level.

- if the user want to scroll around, the repositioning will be turned off for some time, the
map center will stay on the position the user decided. If the user is stationary for a longer
time, the recenter wont happen. If the user is out of the map view, we should show a little 
marker on the edge of the map to show the direction where he is located.

-If the user starts walking the re centering will turn on again. Maybe some more distance is
needed to determine if a new trail point is getting created or not.


################################
#	Zooming
################################
- The interaction should be quite clear, if the user zooms in, the zoom level of the map 
will be increased accordingly to the user interaction.

- This will also change the distance rings around the user position. Not every distance
makes sense on each zoom level.

- The zoom level will be fixed to some boundaries, it's a hunting region application, not a 
google earth alternative. I will focus on that purpose for now and keep it simple.



################################
#	Trail interaction
################################
- The trail view can show several trails, the user should be able to select different trails
from a table view, if the user decides he want to see the trail from a specific date or the 
last few days he should get different trails shown in the map view. Each trail needs to get 
a color. The colors should not be selected, they will follow a predefined rule (needs to be
defined there are a few color items like in a hue map ... starting from red to green if we 
have 1 we have red if we have 2 we will have red and green if we have 3 or more the red and 
green will be divided accordingly to the number of trails we have)

- the trail shall show the current way points where the user comes from. the map wont show 
the whole trail if the zoom level does not show all items.

- there need to be a table view or a list with the different trails. Selecting a specific
trail should highlight the trail in the map. The list item needs to be checkable or should
have a toggle function (no regular checkbox)
